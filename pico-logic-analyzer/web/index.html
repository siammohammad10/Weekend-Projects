Set up your Pico

Four steps, about a minute. You only flash once.

  1. 1Pick your board

  2. 2Download the firmware
    Download .uf2
  3. 3Flash it

    Hold the BOOTSEL button while you plug the Pico into USB, then let go. A drive called RPI-RP2 opens. Drag the file onto it. The Pico restarts on its own when it's done.

  4. 4Connect

    The browser lists only Raspberry Pi devices, so pick the one it shows. Works in Chrome and Edge on a computer.
