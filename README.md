# Weekend projects

Things I build on weekends, mostly tools for problems I run into at school. Each folder is its own project with its own README.

| Project | What it is | Links |
| --- | --- | --- |
| [Pico Logic Analyzer](pico-logic-analyzer/) | An 8-channel logic analyzer made from a Raspberry Pi Pico. PIO and DMA capture into RAM, and the browser draws the waveforms and decodes UART, I2C and SPI over Web Serial. | [Open the app](https://siammohammad10.github.io/Weekend-Projects/pico-logic-analyzer/web/) · [README](pico-logic-analyzer/README.md) |
| [ECE Stockroom](ece-stockroom/) | A web app for the Texas Tech ECE stockroom. Students order and rent parts against their team's budget, and staff run the front desk, inventory, lab access and the 3D print queue. | [Live demo](https://siammohammad10.github.io/Weekend-Projects/ece-stockroom/) · [README](ece-stockroom/README.md) |
